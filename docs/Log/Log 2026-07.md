- 2026-07-12: sprite-pass deviation 1 - **authoring goes through a generator, not by hand-editing the strings**. Hand-counting 40x40 and 48x48 char grids in a text file proved too error-prone (a first hand-authored attempt was scrapped), so `scripts/gen-sprites.mjs` draws each sprite from primitives (rect/disc/ring) into a char grid, validates every row width / frame height, and emits `src/sprite-data.ts` (marked AUTO-GENERATED). Output is still diffable palette-enforced pixel-strings exactly as the [Sprite Spec](../Design/Sprite%20Spec.md) Authoring section intends - the generator is just the editing surface. `node scripts/gen-sprites.mjs` regenerates; `--preview` prints ASCII to eyeball shapes without a browser. Future sprite tweaks: edit the shape functions in the generator, not `sprite-data.ts`.
